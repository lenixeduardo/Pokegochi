# Pokegochi

Jogo mobile de cuidados e evolução de Pokémon, desenvolvido como projeto de fã não oficial.

## Estado

O repositório foi inicializado para receber a versão V9 (Fase 4). **O pacote do jogo ainda não foi importado**; o código e os recursos binários não estão disponíveis neste repositório neste momento.

## Pacote previsto

- `index.html`: interface e lógica do jogo
- `assets/sprites/`: nove sprites PNG originais
- `assets/scenes/`: cinco cenários
- `assets/objects/`: objetos independentes
- `sw.js` e manifesto PWA: suporte offline
